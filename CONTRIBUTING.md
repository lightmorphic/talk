# Contributing

Thanks for even considering it. Lightmorphic Talk is a one-person
project, and the honest truth is I can't take on reviewing or
maintaining outside code right now — so I'm not accepting pull
requests at the moment.

What genuinely helps:

- **Bug reports** — open an issue with what you did, what you
  expected, and what happened instead. Logs from `talk.log` are gold.
- **Feature ideas and feedback** — open an issue too. I read every
  one.

If you'd still like to send a pull request anyway, I may not be able
to look at it for a long time, and I'd rather set that expectation now
than leave you waiting. Thanks for understanding, and for using the
app.
